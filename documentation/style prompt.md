# Design system guidelines

* Use a base font-size of 14px
* Use sans-serif base font such as Helvetica
* Time formats should always be in the format “4:00” - minutes and seconds
* Use a contemporary, but minimalist color scheme. It should feel refined; Apple is a good reference point
* Center major page elements (tables and forms) to the page, but left justify the headers and contents (inclusive of tags such as h1, h2, p etc.)
* Every form element must be styled the same
* Every table element must be styled the same

## Form Elements

* Create uniform styling across form elements
* Provide a background color that differentiates the form from the background of the main site
* Provide even spaceing between form elements
* All input field sizes should be the same
* Provide equal spacing between labels and inputs
